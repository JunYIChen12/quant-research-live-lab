# Quant Research Live Lab

一个以证据门槛、人工批准和失效即停为核心的量化研究与小额实盘验证系统。

> [!WARNING]
> 本项目处于初始化阶段，尚不具备实盘条件，不承诺盈利，也不构成投资建议。仓库不会保存交易所密钥、账户导出、实盘数据库或原始交易日志。

## 核心原则

- 自动研究，人工晋级。
- 策略版本冻结后才能进入验证区。
- 实盘结果可以返回研究区，但不能直接修改运行中的策略。
- 机器可以自动降级、暂停和停止，不能自动增加本金、杠杆、持仓数或亏损限额。
- 所有运行闸门采用 fail-closed：信息缺失或状态不明时禁止开仓。

## 当前范围

首阶段仅建立可审计的安全内核：

1. 研究与实盘执行隔离；
2. 冻结策略、证据和人工批准闸门；
3. 1 倍杠杆、逐仓、单持仓的运行时约束；
4. 按已实现盈亏、浮动盈亏和预计平仓成本计算刹车条件；
5. GitHub 协作、安全报告和持续集成规范。

候选验证入口和单正式 Dry-run 监督/Web 基线已纳入代码，但这不等于真实 Dry-run、盈利、实盘或发布授权；Windows 宿主与通知仍未完成。

## 流程

研究候选 → 回测与独立验证 → 冻结版本与证据包 → 人工批准 → 小额执行 → 审计复盘 → 返回研究区。

研究区和执行区之间只允许冻结制品单向进入；实盘数据返回研究区后必须生成新版本并重新考试。

## 本地开发

要求 Python 3.12+。创建虚拟环境后安装开发依赖，依次运行 ruff check . 和 pytest。

示例风险参数位于 config/risk-limits.example.toml。它只是模板，不是实盘授权文件。

发布规则位于 docs/governance/RELEASE_POLICY.md。运行程序不能依赖手工填写的布尔值放行，而必须读取发布清单并核对 Git 提交、带注释标签、制品 SHA-256 和已合并 PR。
