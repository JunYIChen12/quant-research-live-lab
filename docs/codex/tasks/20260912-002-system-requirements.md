## 需求背景与此前对齐方向

- 短期用户是本人，核心痛点是情绪化扛单和亏损后扩大风险；目标是减少人工参与，而非仅增加提醒。
- 产品希望覆盖研究、提出假设、生成候选策略、验证、筛选、执行和复盘，而不只是自动下单。
- 此前上下文已对齐第一阶段先模拟、暂不动用真实资金；新策略或新版本进入实盘仍需单独批准。
- 系统可以在授权范围内自主调整，但不能自行突破用户授权的硬风险上限。
- 没有候选达标时告知用户，由用户决定继续研究还是改变筛选标准；系统不得自行降低标准。改变筛选标准不等于放宽风险上限，变更后须重新验证。
- “没有合格策略”和“证据不足”可以是研究结论；用户希望用 ROI 衡量收益目标，不构成收益承诺，也不自动替代技术正确性与风险约束。
