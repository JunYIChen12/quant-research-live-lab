# Repository Instructions

1. Start with `README.md`, then read `docs/STATUS.md`, `docs/USER_REQUIREMENTS.md`, and `docs/PROJECT_HISTORY.md` as needed.
2. Keep one Issue to one objective and one implementation Pull Request.
3. Prefer the smallest reproducible research experiment over new infrastructure.
4. Never read, create, print, or commit exchange credentials or account exports.
5. Keep research, Dry-run, and live data physically separate.
6. Do not start Dry-run, live trading, or exchange-account access without separate explicit approval.
7. Missing or contradictory safety state fails closed.
8. Never describe backtests or a small number of trades as proof of profitability.
9. Do not add live exchange adapters unless a separately reviewed milestone authorizes them.
10. A factor research result is evidence for strategy research, not authorization to trade.
