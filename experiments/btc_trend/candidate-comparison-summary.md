## 逐项判定

| 标准（压力成本） | Donchian 55/20 | SMA200 过滤 |
|---|---|---|
| 三个子区间收益均为正 | 通过 | 通过 |
| 全区间收益为正 | 通过 | 通过 |
| 全区间最大回撤不超过 25% | **失败：51.65%** | **失败：37.88%** |
| 全区间至少 10 笔交易 | 通过：90 | 通过：211 |
| 全区间正常退出收益为正 | 通过：512.59% | 通过：485.83% |
| 正强制平仓贡献不超过总收益 25% | 通过：0% | 通过：20.55% |

SMA200 在 2026 历史评估区间的正常退出为负，正收益完全来自期末强制平仓。虽然预注册的
强制平仓比例只约束全区间，因此这不是额外硬失败项，但它进一步削弱了结果可信度。

## 事实、推断与建议

### 事实

- 16 次预注册运行全部完成，两个候选均在压力成本下保持三个子区间总收益为正。
- Donchian 压力成本全区间最大回撤为 51.65%。
- SMA200 压力成本全区间最大回撤为 37.88%。
- 两个候选都违反唯一失败的硬标准，因此批次为 `EXHAUSTED`。

### 推断

- 这两个简单趋势规则能捕捉部分长期上涨，但没有把历史回撤压到当前研究上限内。
- SMA200 的部分成绩对区间结束时仍开放的仓位敏感。
- 本结果不能证明未来盈利，也不能支持进入 Dry-run。

### 建议

- 不调整 55/20、SMA200 或 25% 回撤标准来制造通过结果。
- 保留两个策略作为已测试反面证据。
- 若继续自动研究，应在新的批次中预注册不同的风险控制假设，而不是围绕本批次结果调参。

## 复现

```powershell
$strategies = @("BtcDonchian5520", "BtcSmaFilter200")
$periods = @("20200101-20240101", "20240101-20260101", "20260101-20260901", "20200101-20260901")
$fees = @(0.001, 0.002)

foreach ($strategy in $strategies) {
  foreach ($period in $periods) {
    foreach ($fee in $fees) {
      freqtrade backtesting `
        --config experiments/btc_trend/config.backtest.json `
        --userdir experiments/btc_trend/user_data `
        --strategy-path experiments/btc_trend/strategies `
        --strategy $strategy `
        --timeframe 4h `
        --timerange $period `
        --fee $fee `
        --cache none `
        --export trades
    }
  }
}
```

原始行情和回测制品保存在 Git 忽略目录，不提交仓库。
